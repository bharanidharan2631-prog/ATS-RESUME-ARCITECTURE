# ATS Resume Analyzer & AI Resume Optimizer

## Overview

An AI-powered ATS Resume Analyzer that evaluates resumes against job descriptions, calculates ATS scores, identifies missing keywords, generates optimized resumes, and sends the generated resume via email.

## Features

* ATS Score Calculation
* Keyword Matching Analysis
* Missing Keyword Detection
* AI Resume Optimization using Groq
* PDF Resume Generation
* Email Delivery
* Streamlit Cloud Deployment

## Tech Stack

* Python
* Streamlit
* Groq API
* ReportLab
* PyPDF2
* SMTP Email Automation
